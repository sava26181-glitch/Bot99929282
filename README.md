# Zenodrop Banner Bot

Telegram-бот для Render.

## Что делает

Пользователь отправляет видео, затем выбирает:
- секунду, на которой вставить баннер;
- длительность баннера;
- количество баннеров: 1, 2 или 3.

В момент вставки исходное видео замораживается на последнем кадре перед баннером. Баннер(ы) проигрываются поверх замороженного кадра. После окончания видео продолжается с того же места.

При 2 баннерах они стоят один выше центра, другой ниже.
При 3 — верх, центр, низ.

## Запуск на Render

1. Создай новый Worker из этого проекта.
2. Build Command: `npm install`
3. Start Command: `npm start`
4. Добавь Secret Environment Variable:
   `BOT_TOKEN=токен_от_BotFather`
5. `banner.mp4` уже лежит в проекте — это загруженный пользователем баннер.

FFmpeg на Render должен быть доступен в окружении. Если в выбранном окружении его нет, используй Dockerfile ниже.

## Docker

Для гарантированного FFmpeg можно создать Dockerfile на базе Node + ffmpeg.

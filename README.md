# Zenodrop Banner Bot — FAST

Бот для Render.

После отправки видео пользователь выбирает:
- секунду вставки;
- длительность;
- 1, 2 или 3 баннера.

Оптимизация:
- исходное видео режется только на две части;
- баннерная часть кодируется отдельно;
- части исходника не перекодируются повторно после создания;
- используется concat demuxer с `-c copy` для финальной сборки, когда параметры сегментов совместимы.

Важно: мгновенная обработка невозможна для любого ролика, потому что FFmpeg должен создать новый видеосегмент с баннером. Но этот вариант существенно быстрее предыдущего.

На Render лучше использовать Worker + Dockerfile.

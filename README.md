# Zenodrop Banner Bot v5 — TikTok

Telegram-бот для вставки видео-баннера.

## Что умеет
- принять обычное видео файлом;
- принять ссылку `https://www.tiktok.com/...` или `https://vm.tiktok.com/...`;
- автоматически скачать TikTok через yt-dlp;
- дать выбрать секунду вставки, длительность и 1/2/3 баннера;
- заморозить исходный кадр на время баннера;
- сохранить звук исходного видео до и после вставки;
- использовать звук самого видео-баннера во время вставки;
- вернуть готовое MP4 в Telegram.

## Render
Используй Background Worker с Docker. В переменных окружения нужен только `BOT_TOKEN` (остальные имеют значения по умолчанию).

Важно: с одним Telegram `BOT_TOKEN` должен работать только один polling-процесс. Если появляется `409 Conflict`, останови старый экземпляр бота.

TikTok может менять защиту/формат выдачи, поэтому иногда конкретная ссылка может не скачаться. В таком случае бот покажет причину в сообщении и в Render Logs.
